# Data provenance

- Dataset: datasets/s-and-p-500, monthly S&P 500 data.
- Retrieved: 2026-10-30 (Japan date).
- Repository: https://github.com/datasets/s-and-p-500
- CSV URL: https://raw.githubusercontent.com/datasets/s-and-p-500/main/data/data.csv
- Original compilation: Robert Shiller, linked from the repository.
- Analysis range: 2000-01 through 2023-06. Later FRED-extended rows excluded to avoid the documented construction change.
- Monthly average prices; not executable month-end prices, and not total returns.
- Source snapshot SHA256: 3a45dffabc414afc298c12159abc84c2875f88175ff3d4473ef7417e725ecac6
- The raw snapshot is preserved as retrieved, including columns not used in the analysis. Zero-filled non-price fields in later rows must not be interpreted as real observations.
- Data rights remain with source providers. See repository terms and upstream sources before redistribution beyond this personal educational portfolio.
